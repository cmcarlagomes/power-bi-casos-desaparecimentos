# 📊 Conecta Desaparecidos — Análise de Dados com Power BI

Projeto de Business Intelligence desenvolvido no Power BI para explorar e visualizar indicadores relacionados a casos de desaparecimentos, utilizando dados fictícios para fins educacionais e demonstrativos.

O dashboard foi desenvolvido para transformar dados em informações visuais, facilitando a compreensão de tendências, distribuição dos casos e indicadores relevantes.

# 🎯 Objetivo do projeto

Desenvolver um dashboard interativo que permita analisar os dados de forma clara e organizada, utilizando recursos de visualização e filtros para explorar diferentes perspectivas dos casos.

# 🖥️ Visão Geral

A primeira página apresenta uma visão consolidada dos principais indicadores, permitindo explorar os totais de casos, os status, a distribuição por sexo, a localização geográfica e a evolução mensal.

![Dashboard Conecta Desaparecidos — Visão Geral](Painel%20da%20Visao-geral.png)

# 🔎 Análise Detalhada

A segunda página aprofunda a análise por faixa etária, evolução dos casos, tempo médio até a localização, motivos ou contextos registrados e distribuição por município.

![Dashboard Conecta Desaparecidos — Análise Detalhada](Painel%20de%20An%C3%A1lise%20Detalhada.png)

# 🛠️ Ferramentas e recursos

- **Power BI Desktop:** desenvolvimento do dashboard e criação das visualizações.
- **DAX:** criação de medidas e indicadores, conforme utilizado no relatório.
- **Visualização de dados:** gráficos, cartões, indicadores e filtros interativos.
- **Análise exploratória:** comparação de indicadores por diferentes categorias.

# 📌 Principais funcionalidades

- Visão geral dos indicadores.
- Análise detalhada por faixa etária.
- Comparação dos status dos casos.
- Visualização da evolução mensal.
- Análise por município e localização geográfica.
- Exploração de motivos ou contextos.
- Filtros e navegação entre páginas.

Os dados utilizados neste projeto são fictícios e têm finalidade exclusivamente educacional e demonstrativa. Os números e indicadores não representam estatísticas oficiais nem casos reais.
